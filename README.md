# OutfitIQ

OutfitIQ is a smart wardrobe app for people who want to spend less time wondering what to wear. It helps turn a real closet into something easier to organize, understand, and use every day.

## What it does

- Add and organize clothing items
- Scan clothes and save useful details about them
- Browse a digital wardrobe
- Build outfits manually or get suggestions
- Plan outfits on a calendar
- Prepare packing lists for trips
- Keep track of clothes that are in the laundry
- Get styling help from the AI coach

## How AI is used

AI helps identify clothing items and create outfit suggestions. Recommendations can take the user's wardrobe, preferences, weather, and occasion into account. The user stays in control and can edit clothing details or choose a different outfit at any time.

## Why I built it

It is easy to forget what is already in your closet, buy something too similar to what you own, or wear the same few things on repeat. OutfitIQ is designed to make those everyday decisions simpler and help people get more use out of their existing clothes.

## Running locally

Install the dependencies and start the development server:

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

## Project status

OutfitIQ is actively being developed. The core wardrobe, outfit, packing, laundry, and coach experiences are in place, with more improvements planned.
